# Core Concepts You Will Learn

## 1. HTML Structure (Page Architecture)

HTML is the skeleton of a webpage.

You will use structured elements like:

```html
<header></header>
<nav></nav>
<main></main>
<section></section>
<footer></footer>
````

This makes your code clean and easy to understand

---

## 2. Multi-Page Navigation

You will connect pages using links:

```html
<a href="game.html">Game</a>
<a href="info.html">Info</a>
<a href="../index.html">Back to Forest</a>
```

This allows users to move between pages

---

## 3. Relative Linking 

You must understand folder paths:

* Same folder:

```html
<a href="game.html">
```

* Going back to main folder:

```html
<a href="../index.html">
```

This is how real websites connect pages

---

## 4. Reusable Layout Design

All pages should follow the same structure:

* Header at top
* Navigation below
* Content in middle
* Footer at bottom

This creates consistency across the site

---

## 5. User Experience (UX Thinking)

You will think like a user:

* Can I find where to click?
* Can I go back easily?
* Is anything confusing?

Your job is to make everything simple and clear

---

# Your Responsibilities

## 1. Build Page Structure

Create HTML layouts for:

## 2. Build Navigation System

Every page must include:

* Links to:

  * Gallery
  * Game
  * Info
* Link back to homepage

Example:

```html
<nav>
  <a href="index.html">Gallery</a>

  <a href="../index.html">Back to Forest</a>
</nav>
```
